Project Synopsis

Guardian AI is an AI-assisted wearable emergency detection and alert system. The device combines heart-rate sensing, motion sensing, camera verification, AI-based event analysis, GPS/GNSS, cellular communication, vibration feedback, rechargeable battery and supplementary solar charging.


During normal operation, the system monitors sensor information continuously. If unusual heart-rate and motion patterns occur together, the AI enters a verification stage.


After verification, the device obtains its current location and sends an emergency notification containing the location to the authorized guardian.


The website demonstrates the complete workflow from sensor monitoring to emergency notification. Live GPS can be displayed when location permission is granted. Actual SMS and WhatsApp delivery requires a secure messaging backend.
